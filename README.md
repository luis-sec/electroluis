# ElectroLuis – Sitio web informativo

Sitio de una sola página para el taller ElectroLuis (Zapopan, Jalisco).
Secciones: Inicio, Servicios, Cómo trabajamos, Nosotros y Contacto.

- Sin dependencias: solo `index.html` (HTML + CSS).
- Responsivo y con botón de WhatsApp.
- Publicación: GitHub Pages (Settings > Pages > rama `main`, carpeta `/root`).
